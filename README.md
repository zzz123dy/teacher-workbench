# 教师智能工作台 · 班级AI助手

> 班主任与任课教师的智能班级管理助手。纯前端（HTML/CSS/JS），数据保存在浏览器本地，无需服务器、无需联网即可使用（导入 Excel/Word 需联网加载解析库，可离线降级）。

## 快速开始
1. 双击打开 `index.html` 即可使用（建议用 Chrome / Edge / 手机浏览器）。
2. 首次打开自动载入**示例数据**（八年级某班、体育老师任班主任），可直接体验。

## PC 端
- 左侧导航栏可**展开/收缩**（点左上角 `‹`）。
- 顶部「📥 导入」可上传 Excel/Word 自动识别归档。
- 顶部🔔查看消息红点提醒；右上角搜索可搜学生/通知。

## 手机端（APP 体验）
- 手机浏览器访问后，点右上角「☰」打开左侧抽屉菜单（含全部模块）。
- **添加到桌面**：浏览器菜单 → “添加到主屏幕”，即获得类 APP 图标（已配置 PWA `manifest.webmanifest`）。

## 核心功能
- 首页工作台：今日课程、班级动态、数据简报、最新通知、学生提醒、待办、常规/特色工作。
- 班级管理：班级信息、花名册、学生档案（基础/学习/评价/成长）。
- 班级事务：座次表（拖动换座、多版本）、值日表（打印）、课表（可编辑）。
- 学情分析：班级平均/合格率/优秀率/短板；单科分数段与进退步；个体成绩趋势。
- 成绩管理：多考试管理、手动/Excel 录入、排名、Excel/PDF 导出。
- 家校沟通：家长通知（已读统计）、私信/群发、沟通记录。
- 资源与工具、消息中心、个人中心（导出/导入整库，方便复制给其他教师）。

## 数据导入（自动识别）
支持 `.xlsx/.xls/.csv/.docx`：
- 学生信息表 → 花名册
- 成绩表（含科目列）→ 成绩
- 课表（星期/节次/科目）→ 课表
- 姓名矩阵 → 座次表
- 值日表 → 值日
- Word → 提取文本后手动归类

## 文件结构
```
teacher-workbench/
├─ index.html          工作台外壳
├─ manifest.webmanifest  PWA 配置（手机添加到桌面）
├─ icon.svg             应用图标
├─ css/style.css        紫色毛玻璃主题
├─ js/store.js          本地数据库（localStorage）
├─ js/data.js           示例数据 & 学科字典
├─ js/charts.js         轻量图表
├─ js/import.js         Excel/Word 识别归档
├─ js/modules.js        首页/班级管理/特色
├─ js/modules2.js       事务/学情/成绩/家校/资源/消息/个人/导入
├─ js/app.js            导航/路由/UI 组件
└─ db-structure.md      数据库结构说明
```

## 复制给其他教师/班级
个人中心 → 导出整库(JSON) 交给同事，对方「导入整库」即可复用全部结构。
重置示例：个人中心 → 重置示例数据。
